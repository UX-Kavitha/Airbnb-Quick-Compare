# Kavitha Sankaran - Product Design Portfolio

A case study portfolio website showcasing the **Airbnb Quick Compare** UX project.

## 🚀 Deploy to Vercel

### Option 1: Deploy via Vercel CLI (Recommended)

1. Install Vercel CLI:
```bash
npm install -g vercel
```

2. Navigate to the project folder and deploy:
```bash
cd site
vercel
```

3. Follow the prompts:
   - Set up and deploy? **Y**
   - Which scope? Select your account
   - Link to existing project? **N**
   - Project name? **kavitha-portfolio** (or your choice)
   - Directory? **.** (current directory)
   - Override settings? **N**

4. Your site will be live at the URL provided!

### Option 2: Deploy via Vercel Dashboard

1. Go to [vercel.com](https://vercel.com)
2. Sign up or log in with GitHub
3. Click "Add New Project"
4. Import this folder (either by:
   - Pushing to GitHub first and importing the repo, OR
   - Drag & drop the entire `site` folder into Vercel dashboard)
5. Click "Deploy"

Your portfolio will be live instantly!
